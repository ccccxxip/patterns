# Система автоматизации сети ресторанов «Ромашка»

## О проекте

Данный проект предназначен для разработки программного обеспечения
для автоматизации сети ресторанов «Ромашка».

В рамках проекта рассматриваются:
- складской учёт;
- производственный учёт;
- курьерская служба;
- финансовый учёт;
- учёт персонала;
- оперативный учёт.
