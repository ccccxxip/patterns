# Домены и сущности

В файле представлены основные сущности, которые будут использоваться при разработке программы для автоматизации сети ресторанов «Ромашка».

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| Ресторан | Ресторан сети «Ромашка». Может работать с посетителями, на доставку или все вместе. | Связан со складом и оперативными заказами. |
| Помещение | Помещение, в котором находится склад. | Связано со складом. |
| Склад | Место, где хранится продукция и другие элементы номенклатуры. | Связан с рестораном, помещением, остатками и инвентаризацией. |
| Группа номенклатуры | Группа, в которую входят элементы номенклатуры. | Связана с номенклатурой и инвентаризацией. |
| Номенклатура | Продукты, материалы и другая продукция, которая используется в системе. | Связана с группой номенклатуры, складом, остатками и производством. |
| Остаток | Количество определённой номенклатуры на конкретном складе. | Связан со складом и номенклатурой. |
| Инвентаризация | Проверка фактического количества продукции на складе. | Связана со складом, номенклатурой и группой номенклатуры. |
| Технологическая карта | Описание того, из чего и как готовится продукция или блюдо. | Связана с номенклатурой, блюдами и другими технологическими картами. |
| Приготовление полуфабриката | Операция по приготовлению полуфабриката. | Связана с технологической картой, номенклатурой и сотрудником. |
| Приготовление блюда | Операция по приготовлению блюда. | Связана с технологической картой, блюдом и сотрудником. |
| Выпуск продукции | Операция, которая фиксирует выпуск готовой продукции. | Связана с номенклатурой, технологической картой и сотрудником. |
| Утилизация продукции | Операция по списанию продукции, которая была утилизирована. | Связана с номенклатурой, складом и сотрудником. |
| Район доставки | Район, в который осуществляется доставка. Для района задаётся стоимость доставки. | Связан с заказами на доставку. |
| Меню | Список блюд, которые можно заказать. Для доставки используется отдельное меню. | Связано с рестораном и блюдами. |
| Блюдо | Готовое блюдо, которое можно приготовить и добавить в меню. | Связано с меню, упаковкой, технологической картой и заказами на доставку. |
| Упаковка | Упаковка, которая используется при доставке блюда. | Связана с блюдом. |
| Группа контрагентов | Группа, в которую входят контрагенты. | Связана с контрагентами. |
| Контрагент | Юридическое лицо, с которым организация проводит взаиморасчёты. | Связан с группой контрагентов и финансовыми документами. |
| Тип оплаты | Способ оплаты, например наличные или банковский перевод. | Связан с финансовыми документами. |
| Финансовый документ | Документ, который используется для учёта поступления или списания денег. | Связан с контрагентом, типом оплаты и сотрудником. |
| Сотрудник | Работник компании, который может участвовать в разных операциях системы. | Связан с графиком работы, сменами и операциями. |
| График работы | Определяет рабочее время сотрудника. | Связан с сотрудниками и рабочими сменами. |
| Рабочая смена | Запись о начале и окончании работы сотрудника. | Связана с сотрудником и графиком работы. |
| Заказ на доставку | Заказ на доставку блюд клиенту. | Связан с рестораном, районом доставки, блюдами и сотрудником. |
| Заказ на пополнение склада | Заказ на пополнение запасов на складе ресторана. | Связан с рестораном, складом, номенклатурой и сотрудником. |
| Заказ на производство | Заказ на производство необходимой продукции. | Связан с рестораном, номенклатурой, технологической картой и сотрудником. |
